# stts

stts is a public repository featured on Mark's GitHub profile: strangers install it. Before any change, read `specs/009-install-and-upgrade/spec.md`, section "Public repo rules", and keep every rule there. In short: it must work on a clean machine with none of our setup, house-only behaviour is a setting our setup writes, and a new part the daemon needs goes into `install.json` and `scripts/install.mjs` in the same commit.
